# Админы шинэчлэл

Контентын нэг засварлагч, үнэ/үнэгүй сонголт/сайтын нэр, хувь эсвэл дүнтэй купон,
өдөр/сар/жилийн хандалт ба орлого, төлбөрийн дэлгэрэнгүй, багийн эрх,
нууц үг солих болон үйлдлийн түүх нэмэгдсэн.

ADMIN бүх хэсэгт, MODERATOR контентод, EDITOR зөвхөн ноорогт өөрчлөлт хийнэ.
Эрх сервер дээр шалгагдана. Идэвхгүй гишүүн болон нууц үг солигдсон session хүчингүй болно.

Картын эрх серверийн cookie session-д холбогдоно. Transaction/advisory lock нь давхар
үнэгүй сонголтоос хамгаална. Refresh дээр нээгдсэн хариулт сэргээгдэнэ.
Төлбөр тухайн сонголтод холбогдож, өөр зочин шалгах боломжгүй.

## Төлбөрийн тохиргоо

`PAYMENT_MODE=mock`: бодит мөнгө авахгүй. Зөвхөн админ төлбөрийн жагсаалтаас
тестийн төлбөрийг батална. Тестийн төлбөр бодит орлогод орохгүй.

QPay холбох backend env:

- `PAYMENT_MODE=live`
- `QPAY_BASE_URL=https://merchant.qpay.mn` (sandbox: `https://merchant-sandbox.qpay.mn`)
- `QPAY_CLIENT_ID`, `QPAY_CLIENT_SECRET`, `QPAY_INVOICE_CODE`
- `QPAY_CALLBACK_BASE_URL=https://tenger-atls-api.vercel.app`

Env оруулаад backend redeploy хийнэ. Token серверт хадгалагдана; invoice, QR,
банк холбоос, callback, payment/check болон MNT дүнг серверээр шалгана.
Sandbox орлого бодит орлогод орохгүй. Бодит credentials байхгүй тул QPay acceptance
test хийгдээгүй. Бодит төлбөр нээхээс өмнө sandbox болон бага дүнгээр баталгаажуулна.

## Шалгалт

- Backend: `npm run build`, `npm test`.
- Isolated mock backend: `node --import tsx tests/operations.integration.ts`.
  QA контент, купон, гишүүнээ цэвэрлэж, тохиргоог буцааж сэргээнэ.
- Frontend: lint, typecheck, build, `npm run test:e2e`.
- Бодит браузер: `TEST_SITE_URL` тохируулаад `node tests/admin-live.mjs`.

Хандалт нь cookie-д суурилсан өдөр бүрийн давтагдаагүй браузерын тоо; IP, нэр цуглуулахгүй.
Тайлан нь Улаанбаатарын цагтай; сонгосон хугацаанд үүссэн эсвэл төлөгдсөн нэхэмжлэхийг харуулна.
Орлого нь нэхэмжлэх үүсгэсэн өдрөөр биш, бодитоор төлөгдсөн өдрөөр тооцогдоно.
Шинэ хүснэгт нэмсэн migration нь өмнөх контентыг устгахгүй.

Энэ хувилбарт хэрэглэгчийн имэйл бүртгэл, төхөөрөмж хооронд эрх сэргээх, зураг файл
upload, төлбөрийн буцаалт нэмэгдээгүй. Одоогийн guest урсгал cookie-д суурилна.
